# AutoTestGenerator

Десктопное приложение для автоматической генерации и запуска автотестов веб-приложения на основе XML-файла метаданных.

Приложение генерирует готовый проект с тестами на Selenium + JUnit, запускает их в браузере Chrome и выдаёт HTML-отчёт с результатами и скриншотами.

---

## Требования

| Что | Версия | Примечание |
|-----|--------|------------|
| Java | 17 или выше | обязательно |
| Apache Maven | 3.8 или выше | обязательно |
| Google Chrome | последняя версия | для запуска тестов |
| Интернет | — | нужен при первом запуске для загрузки зависимостей |

> ChromeDriver устанавливается **автоматически** через WebDriverManager — скачивать вручную не нужно.

---

## Установка на Windows 10 / 11

### 0. Откройте PowerShell

Нажмите `Win + X` и выберите **Terminal** или **PowerShell**.

> Если установка через `winget` попросит права администратора — соглашайтесь.

---

### 1. Установите Java 17

```powershell
winget install --id EclipseAdoptium.Temurin.17.JDK -e
```

Проверьте установку:

```powershell
java -version
```

Ожидаемый вывод:

```
openjdk version "17..."
```

---

### 2. Установите Maven

```powershell
winget install --id Apache.Maven -e
```

Проверьте установку:

```powershell
mvn -version
```

---

### 3. Установите Google Chrome

```powershell
winget install --id Google.Chrome -e
```

---

### 4. Перезапустите PowerShell

Закройте PowerShell полностью и откройте заново — это нужно, чтобы Windows увидела команды `java` и `mvn`.

---

### 5. Перейдите в папку проекта

Если проект лежит в папке `Downloads`:

```powershell
cd "$env:USERPROFILE\Downloads\AutoTestGenerator"
```

Если в другом месте — замените путь:

```powershell
cd "C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\Desktop\AutoTestGenerator"
```

Проверьте, что вы в правильной папке — в списке файлов должен быть `pom.xml`:

```powershell
dir
```

---

### 6. Запустите приложение

```powershell
mvn javafx:run
```

При первом запуске Maven скачает все зависимости — это займёт несколько минут. Последующие запуски будут быстрее.

После завершения загрузки откроется окно AutoTestGenerator.

---

## Инструкция по использованию

### Шаг 1 — Выберите XML-файл

Нажмите кнопку выбора файла и укажите ваш XML-файл с описанием метаданных (расширение `.xml`).

### Шаг 2 — Проверьте параметры

По умолчанию приложение уже заполняет поля:

| Поле | Значение по умолчанию |
|------|-----------------------|
| URL сайта | `https://rrpo.cmirit.ru/E3Core` |
| Логин | `test` |
| Папка для тестов | `generated-tests` |
| Подсистема | `Гаражно-строительные кооперативы` |

При необходимости измените URL, логин, пароль и папку назначения.

### Шаг 3 — Разберите XML

Нажмите кнопку **Разобрать XML** — приложение прочитает файл и покажет найденные сущности.

### Шаг 4 — Сгенерируйте тесты

Нажмите кнопку **Генерировать тесты** — приложение создаст готовый проект с автотестами в указанной папке.

### Шаг 5 — Запустите тесты

Нажмите кнопку **Запустить тесты** — Chrome откроется автоматически и начнёт выполнять тесты на указанном сайте.

> Внутри приложение запускает `mvn test` в папке сгенерированного проекта.

### Шаг 6 — Посмотрите результаты

После завершения приложение покажет, где найти результаты:

| Что | Где |
|-----|-----|
| HTML-отчёт | `generated-tests/target/site/surefire-report.html` |
| Скриншоты | `generated-tests/target/screenshots/` |

## Возможные проблемы

**Команды `java` или `mvn` не найдены**
→ Закройте и снова откройте PowerShell после установки

**Приложение не запускается**
→ Убедитесь, что установлена именно Java **17**: `java -version`

**Зависимости не скачиваются**
→ Проверьте подключение к интернету — при первом запуске Maven обращается к Maven Central

**Chrome не открывается при запуске тестов**
→ Убедитесь, что Google Chrome установлен и обновлён до последней версии

**Ошибка при загрузке XML**
→ Убедитесь, что файл имеет расширение `.xml` и соответствует формату метаданных приложения
